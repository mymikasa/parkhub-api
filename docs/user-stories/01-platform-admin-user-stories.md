## 用户故事

### 故事 1：创建租户用户账号 [US-AUTH-001]

**优先级**: P0

**【用户故事】**
**作为**：平台管理员（详见 [_roles.md](_roles.md)）
**我希望**：为新租户创建租户管理员账号，并指定其角色
**从而**：让租户方人员能够登录系统并管理自己的业务

**【验收标准】**

**场景 1：成功创建租户管理员账号**
```gherkin
Given 平台管理员已登录，且目标租户已存在
When 平台管理员填写用户名、密码、真实姓名、邮箱并指定角色为 tenant_admin，提交创建
Then 系统创建用户并返回用户信息，新账号处于激活状态，且绑定了对应 tenant_id
```

**场景 2：用户名已被占用**
```gherkin
Given 系统中已存在用户名 "admin_tenant_01"
When 平台管理员尝试用相同用户名创建新用户
Then 系统提示"用户名已存在"，不创建用户
```

**场景 3：密码不符合最低长度要求**
```gherkin
Given 平台管理员填写了有效的用户信息
When 平台管理员输入的密码少于 8 位
Then 系统提示"密码长度不足"，不创建用户
```

### 故事 2：批量导入用户 [US-AUTH-002]

**优先级**: P1

**【用户故事】**
**作为**：平台管理员（详见 [_roles.md](_roles.md)）
**我希望**：一次性批量导入多个用户账号
**从而**：快速完成大批量用户的初始化，减少重复操作

**【验收标准】**

**场景 1：批量导入全部成功**
```gherkin
Given 平台管理员准备了合法的用户数据列表（用户名、密码、角色均填写）
When 平台管理员提交批量导入请求
Then 系统返回导入结果：total 总数、success 成功数、failed 失败数为 0，errors 为空
```

**场景 2：部分用户数据非法导致部分失败**
```gherkin
Given 用户列表中包含 1 条用户名已存在的记录和 3 条正常记录
When 平台管理员提交批量导入
Then 系统返回 failed=1，并在 errors 中注明失败条目的索引和原因；其余 3 条正常导入
```

### 故事 3：查看用户列表 [US-AUTH-003]

**优先级**: P0

**【用户故事】**
**作为**：平台管理员（详见 [_roles.md](_roles.md)）
**我希望**：按租户、角色、状态、关键词搜索和分页浏览用户列表
**从而**：快速定位目标用户，进行后续管理操作

**【验收标准】**

**场景 1：按租户 ID 筛选用户**
```gherkin
Given 系统中存在多个租户的用户
When 平台管理员传入 tenant_id 查询用户列表
Then 系统仅返回属于该租户的用户，并按分页规则返回结果
```

**场景 2：按关键词搜索**
```gherkin
Given 系统中存在用户名包含 "zhang" 的多个用户
When 平台管理员传入 keyword="zhang" 查询用户列表
Then 系统返回所有用户名或真实姓名匹配的用户
```

### 故事 4：冻结和解冻用户 [US-AUTH-004]

**优先级**: P0

**【用户故事】**
**作为**：平台管理员（详见 [_roles.md](_roles.md)）
**我希望**：冻结异常账号、解冻恢复正常账号
**从而**：及时控制安全风险，同时支持业务恢复

**【验收标准】**

**场景 1：冻结激活状态的用户**
```gherkin
Given 用户当前处于激活状态
When 平台管理员提交冻结该用户的请求
Then 用户状态变为"已冻结"，该用户后续登录时被拒绝，提示账号已被冻结
```

**场景 2：解冻已冻结的用户**
```gherkin
Given 用户当前处于冻结状态
When 平台管理员提交解冻请求
Then 用户状态变为"激活"，该用户可以正常登录
```

**场景 3：对已冻结用户再次冻结**
```gherkin
Given 用户当前处于冻结状态
When 平台管理员再次提交冻结请求
Then 系统提示无效的状态转换，不执行操作
```

### 故事 5：重置用户密码 [US-AUTH-005]

**优先级**: P0

**【用户故事】**
**作为**：平台管理员（详见 [_roles.md](_roles.md)）
**我希望**：为忘记密码的用户重置密码
**从而**：帮助用户恢复账号访问能力，减少人工支持成本

**【验收标准】**

**场景 1：成功重置密码**
```gherkin
Given 平台管理员指定了目标用户 ID 和新密码（≥8 位）
When 平台管理员提交重置密码请求
Then 系统更新用户密码，该用户可以用新密码登录
```

**场景 2：新密码长度不足**
```gherkin
Given 平台管理员指定了目标用户 ID
When 平台管理员输入的新密码少于 8 位
Then 系统提示"密码长度不足"，不执行密码重置
```

### 故事 6：编辑用户信息 [US-AUTH-006]

**优先级**: P1

**【用户故事】**
**作为**：平台管理员（详见 [_roles.md](_roles.md)）
**我希望**：修改用户的用户名、邮箱、手机号、真实姓名或角色
**从而**：在用户信息变更时保持系统数据准确

**【验收标准】**

**场景 1：成功更新部分字段**
```gherkin
Given 平台管理员选择了目标用户
When 平台管理员只修改了真实姓名字段并提交
Then 系统更新该字段，其他字段保持不变，返回更新后的用户信息
```

**场景 2：用户不存在**
```gherkin
Given 平台管理员传入了一个不存在的 user_id
When 提交更新请求
Then 系统提示"用户不存在"，不执行操作
```
