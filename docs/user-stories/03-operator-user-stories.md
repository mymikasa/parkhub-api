## 用户故事

### 故事 1：查看和修改个人资料 [US-AUTH-010]

**优先级**: P1

**【用户故事】**
**作为**：操作员（详见 [_roles.md](_roles.md)）
**我希望**：查看并更新自己的真实姓名、邮箱和手机号
**从而**：保持个人联系信息的准确性

**【验收标准】**

**场景 1：成功更新个人资料**
```gherkin
Given 操作员已登录
When 操作员修改真实姓名并提交保存
Then 系统更新个人资料并返回最新用户信息，其他字段不变
```

**场景 2：只更新邮箱**
```gherkin
Given 操作员已登录
When 操作员只修改邮箱字段并提交
Then 系统仅更新邮箱，其他字段保持不变
```

### 故事 2：修改自己的密码 [US-AUTH-011]

**优先级**: P0

**【用户故事】**
**作为**：操作员（详见 [_roles.md](_roles.md)）
**我希望**：通过验证旧密码后设置新密码
**从而**：在密码泄露或定期更换场景下保护账号安全

**【验收标准】**

**场景 1：旧密码正确，成功修改**
```gherkin
Given 操作员已登录
When 操作员输入正确的旧密码和合法的新密码（≥8 位），提交修改
Then 系统更新密码，操作员可用新密码重新登录
```

**场景 2：旧密码错误**
```gherkin
Given 操作员已登录
When 操作员输入错误的旧密码
Then 系统提示"原密码不正确"，不更新密码
```

**场景 3：新密码不足 8 位**
```gherkin
Given 操作员已登录，旧密码正确
When 操作员输入的新密码少于 8 位
Then 系统提示"密码长度不足"，不执行更新
```

### 故事 3：查看当前登录用户信息 [US-AUTH-012]

**优先级**: P0

**【用户故事】**
**作为**：操作员（详见 [_roles.md](_roles.md)）
**我希望**：随时查看自己的当前账号信息
**从而**：确认当前登录身份和角色权限

**【验收标准】**

**场景 1：正常获取当前用户信息**
```gherkin
Given 操作员已通过有效 token 登录
When 操作员请求获取当前用户信息
Then 系统返回该操作员的 user_id、用户名、角色、租户 ID、真实姓名等信息
```

**场景 2：token 已过期**
```gherkin
Given 操作员持有已过期的 access token
When 操作员请求获取当前用户信息
Then 系统返回未认证错误，提示 token 无效或已过期
```
