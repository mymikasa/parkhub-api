# ParkHub 用户角色定义

本文件是 ParkHub 系统中所有用户故事的统一角色参考。用户故事中的角色必须引用此定义，禁止在单个故事文件中重复定义角色。

---

## 角色列表

### 平台管理员 (Platform Admin)

- **定义**: 拥有平台全局权限的超级管理员，通常为 SaaS 平台运营方内部人员。
- **职责**: 管理所有租户、创建平台级用户、查看全局统计数据。
- **标识**: `role = platform_admin`，`tenant_id` 为空（不属于任何租户）。

### 租户管理员 (Tenant Admin)

- **定义**: 某个租户（停车运营商）的管理员，管理本租户内的用户、车场和业务配置。
- **职责**: 创建和管理租户内的操作员账号、查看本租户数据。
- **标识**: `role = tenant_admin`，绑定特定 `tenant_id`。

### 操作员 (Operator)

- **定义**: 租户内的日常操作人员，执行具体业务操作（如出入场记录、订单处理）。
- **职责**: 执行租户授权范围内的业务操作，无用户管理权限。
- **标识**: `role = operator`，绑定特定 `tenant_id`。

### 普通用户 (Regular User)

- **定义**: 通过移动端或小程序使用停车服务的终端消费者。
- **职责**: 查询停车记录、支付费用、管理个人信息。
- **标识**: 通过手机号注册，不属于任何租户的内部角色。

---

## 角色权限边界

| 操作 | Platform Admin | Tenant Admin | Operator | Regular User |
|------|---------------|--------------|----------|--------------|
| 管理所有租户 | ✅ | ❌ | ❌ | ❌ |
| 管理本租户用户 | ✅ | ✅ | ❌ | ❌ |
| 执行业务操作 | ✅ | ✅ | ✅ | ❌ |
| 管理个人信息 | ✅ | ✅ | ✅ | ✅ |
| 修改自己密码 | ✅ | ✅ | ✅ | ✅ |

---

## 更新流程

当需要新增或修改角色时：
1. 更新本文件中的角色定义和权限边界表格。
2. 在相关用户故事文件中引用新角色。
