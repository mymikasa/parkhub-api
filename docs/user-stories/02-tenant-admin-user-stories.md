## 用户故事

### 故事 1：创建租户内操作员账号 [US-AUTH-007]

**优先级**: P0

**【用户故事】**
**作为**：租户管理员（详见 [_roles.md](_roles.md)）
**我希望**：在本租户范围内创建操作员账号
**从而**：让一线操作员能够登录系统执行日常业务

**【验收标准】**

**场景 1：成功创建操作员**
```gherkin
Given 租户管理员已登录，且其 tenant_id 已确认
When 租户管理员填写用户名、密码、真实姓名，角色指定为 operator，提交创建
Then 系统创建用户并绑定到当前租户，账号处于激活状态
```

**场景 2：试图创建 platform_admin 角色用户**
```gherkin
Given 租户管理员已登录
When 租户管理员尝试指定 platform_admin 角色创建用户
Then 系统拒绝请求，提示无权创建该角色
```

### 故事 2：查看本租户用户列表 [US-AUTH-008]

**优先级**: P0

**【用户故事】**
**作为**：租户管理员（详见 [_roles.md](_roles.md)）
**我希望**：查看本租户内所有用户的状态和信息
**从而**：了解团队成员账号状态，及时发现异常

**【验收标准】**

**场景 1：只能查看本租户用户**
```gherkin
Given 租户管理员已登录
When 租户管理员查询用户列表
Then 系统仅返回属于该租户的用户，不暴露其他租户的数据
```

### 故事 3：冻结本租户用户 [US-AUTH-009]

**优先级**: P1

**【用户故事】**
**作为**：租户管理员（详见 [_roles.md](_roles.md)）
**我希望**：冻结或解冻本租户内的操作员账号
**从而**：在人员离职或账号异常时快速阻断访问

**【验收标准】**

**场景 1：成功冻结本租户操作员**
```gherkin
Given 租户管理员选择了本租户内一个激活状态的操作员
When 租户管理员提交冻结请求
Then 该操作员状态变为"已冻结"，后续登录被拒绝
```

**场景 2：尝试冻结其他租户的用户**
```gherkin
Given 租户管理员已登录
When 租户管理员传入其他租户用户的 user_id 进行冻结
Then 系统拒绝请求，提示无权操作或用户不存在
```
